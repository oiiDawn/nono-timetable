# 03 — 迁移桌面周视图与月视图

**What to build:** 使用 HeroUI v3 默认视觉重写桌面课表，让用户继续通过周视图和月视图浏览、定位和操作课程，同时完整保留现有时间布局与日期导航能力。

**Blocked by:** 01 — 接入 HeroUI v3 并完成登录入口迁移。

**Status:** ready-for-agent

- [ ] 用户可以切换周视图和月视图，并可前后导航及回到当前日期。
- [ ] 周视图保留日期选择、空闲时间格新增、重叠课程布局、当前时间线和内部滚动。
- [ ] 月视图保留日期选择、课程查看和从日期单元格发起新增的桌面交互。
- [ ] 课程标题、时间和重复标记改用 Lucide 与 HeroUI 风格呈现。
- [ ] 深色和浅色模式下，课程块、网格、选中日期、今天和当前时间均有足够辨识度。
- [ ] 桌面 Chrome 和 Edge 中不出现布局回退或横向溢出。
