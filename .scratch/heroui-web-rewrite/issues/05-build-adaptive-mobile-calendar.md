# 05 — 实现手机自适应课表

**What to build:** 为手机浏览器提供适合触控和窄屏的课表形态：周模式显示日期选择器与单日时间轴，月模式显示紧凑月历与所选日课程列表，让核心查看和编辑流程无需横向滚动或精确鼠标操作。

**Blocked by:** 03 — 迁移桌面周视图与月视图；04 — 迁移完整课程编辑流程。

**Status:** ready-for-agent

- [ ] 手机周模式通过日期选择器切换一周中的日期，并仅展示所选日期的时间轴和课程。
- [ ] 用户可以点击单日时间轴的空闲位置，为所选日期和时间新增课程。
- [ ] 手机月模式显示紧凑月历，并在下方显示所选日期的课程列表。
- [ ] 所选日课程列表包含明确的添加课程行，单击月历日期只负责选择，避免误触新增。
- [ ] 用户可以从手机课表完成查看、新增、编辑和删除课程的完整流程。
- [ ] 手机主体采用自然页面滚动，在 375px iPhone Safari 中无横向溢出、双重滚动或被软键盘遮挡的关键操作。
