# 02 — 重写响应式应用栏与全局操作

**What to build:** 使用 HeroUI 和 Lucide 重写应用栏，保留现有名称及图标，并让订阅地址、回到今天、退出和主题切换在桌面与手机浏览器上都以一致的图标操作方式工作。

**Blocked by:** 01 — 接入 HeroUI v3 并完成登录入口迁移。

**Status:** ready-for-agent

- [ ] 应用栏保留“排课表”名称与现有应用图标。
- [ ] 复制订阅地址、回到今天、退出和主题切换均使用 Lucide 图标按钮。
- [ ] 每个图标按钮具有可见 Tooltip、准确的无障碍名称和清晰的键盘焦点状态。
- [ ] 复制成功和普通 API 错误使用应用内消息提示，不再依赖浏览器提示框。
- [ ] 用户可以在跟随系统、浅色和深色体验之间进行持久化的手动切换。
- [ ] 应用栏在桌面和 375px 手机宽度下均无拥挤或横向溢出。
