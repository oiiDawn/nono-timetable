# 04 — 迁移完整课程编辑流程

**What to build:** 使用 HeroUI 表单控件和对话框重写课程新增、编辑、重复设置、冲突处理和删除流程，在不改变排课规则或 API 契约的前提下提供完整、响应式的编辑体验。

**Blocked by:** 01 — 接入 HeroUI v3 并完成登录入口迁移。

**Status:** ready-for-agent

- [ ] 用户可以新增和编辑课程名称、日期、起止时间、备注及重复规则。
- [ ] 自定义重复频率、重复星期和结束条件的行为与现状一致。
- [ ] 时间冲突以清晰的就地提示呈现，并仍允许用户继续保存。
- [ ] 单次、未来和全部循环课次的保存及删除范围选择保持可用。
- [ ] 删除课程和移除失效单次调整使用应用内确认对话框，不再调用浏览器原生确认框。
- [ ] 表单校验就地显示，不再调用浏览器原生提示框。
- [ ] 表单在桌面使用居中对话框，在手机使用带固定标题及操作区的全屏对话框，内容可独立滚动。
