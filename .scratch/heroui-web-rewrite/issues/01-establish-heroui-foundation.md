# 01 — 接入 HeroUI v3 并完成登录入口迁移

**What to build:** 为 Web 应用接入 HeroUI v3、Lucide、全局组件上下文、消息提示和深浅色基础，并率先迁移登录与初始加载体验，形成一条可运行、可验证的 HeroUI 用户链路。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 应用使用 HeroUI v3 和 Lucide，并能在现有 React 19、Tailwind CSS v4 构建中正常运行。
- [ ] 登录、登录错误和初始登录状态检查使用 HeroUI 呈现，认证行为与现状一致。
- [ ] 默认跟随系统深浅色，且主题基础可供后续界面复用。
- [ ] 全局消息提示能力已接入，可供后续操作反馈使用。
- [ ] 类型检查、生产构建和现有自动化测试通过。
